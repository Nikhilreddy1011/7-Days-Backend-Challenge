# Day 1 - URL Shortener API

A REST API for converting long URLs into short URLs.

## Technologies

- Node.js
- Express.js
- MongoDB
- Mongoose
- NanoID

## Features

- Create short URLs
- Redirect short URLs
- URL validation
- Click tracking
- Duplicate URL detection
- Global error handling

## API Endpoints

POST /api/shorten

GET /:shortCode

## Run Locally

npm install

npm run dev
